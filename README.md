# Telegram Контакты

Локальная программа для macOS с русским интерфейсом. Использует Telethon и Telegram API для поиска публичных контактов сообществ. Репозиторий: [tg-search](https://github.com/osipart777888-coder/tg-search).

## Запуск и поиск

1. Откройте **Telegram Контакты.app** на рабочем столе или `Запустить.command` в проекте.
2. Во вкладке **Вход в Telegram** укажите собственные API ID / API Hash из [my.telegram.org](https://my.telegram.org), нажмите **Сохранить API**. Действующие настройки сохраняются при обновлении. Войти можно по коду или QR: на телефоне Telegram → Настройки → Устройства → Подключить устройство. Код и пароль 2FA вводятся только в локальное окно.
3. Во вкладке **Поиск контактов** выберите тему (юристы, строители и другие), поисковые слова, роли, тип сообществ, город и минимальную аудиторию. Можно задать свои публичные `@ники` или ссылки `t.me/ник`; они проверяются первыми. Для поиска только по ним очистите ключевые слова.
4. В разделе **Настройки поиска и ограничения** задайте объём работы и нажмите **Начать поиск**. **Стоп** сохраняет найденное и контрольную точку.
5. **Открыть TXT** открывает автоматически созданный список новых аккаунтов. **Сохранить TXT как…**, **Источники CSV** и **Вся база TXT** создают повторную выгрузку с выбранными фильтрами типа контакта и достоверности.

TXT: один `@ник` на строку, UTF-8 с BOM для Блокнота/TextEdit. CSV: разделитель `;`, Telegram ID, роль, сообщество, подтверждающий источник, метод, достоверность и дата проверки. Ячейки защищены от выполнения формул. В таблице видны источники; двойной щелчок открывает профиль.

Чтобы скопировать контакт, выделите строку и нажмите **Копировать ник** или **⌘C** (на других системах — Ctrl+C). **Копировать ссылки** копирует ссылки на источники выбранных контактов. Можно выделить несколько строк или нажать ⌘A в таблице и скопировать все показанные ники. В поле источников и журнале выделенный текст также копируется через ⌘C; правый щелчок открывает меню копирования. Копирование работает и при русской раскладке клавиатуры.

Для входа под другим номером откройте **Вход в Telegram → Сменить аккаунт** рядом с номером. После завершения прежнего входа введите новый номер и запросите код либо выберите QR. Пока аккаунт подключён, номер показан только для чтения: редактирование текста само по себе не меняет Telegram-сессию. Кнопка **Другой номер** позволяет начать заново во время ввода кода или 2FA. История и выгрузки остаются общими; действующее ограничение Telegram сохраняется. Обновление программы не восстанавливает сессию, из которой пользователь вышел.

## Поиск самих каналов и групп по названию

В списке **Кого искать** выберите **Только каналы и группы** и введите слова или фразы через запятую, например `юрист, адвокат`. Подходят сообщества, в названии которых есть хотя бы один указанный вариант, без учёта регистра. Совпадения только в @нике, описании или публикациях отбрасываются. В этом режиме город также проверяется только в названии. Telegram возвращает ограниченную выдачу: режим не гарантирует полный список всех сообществ с таким названием.

Если Telegram не вернул подходящие названия, программа пробует варианты написания запроса латиницей для поиска публичных ников. Найденные кандидаты всё равно проходят проверку исходных слов и города в названии. Всего до 100 поисковых запросов, каждый учитывается в общем бюджете API; дополнительные варианты сохраняются для продолжения. Журнал показывает, сколько сообществ вернул Telegram и сколько названий совпало. Можно также указать известные публичные ссылки в списке сообществ.

Фильтр **Все / Группы / Каналы**, минимум участников, лимит сообществ и API-операций продолжают действовать. Публикации, контакты людей и администраторы не собираются; соответствующие настройки и лимит новых контактов отключены. Если минимум участников равен нулю и фильтр РФ выключен, описания дополнительно не запрашиваются. При заданном минимуме метаданные могут запрашиваться для проверки аудитории, но текст описания не используется для совпадения темы.

Результат — название, тип, @ник и ссылка на сообщество, а также размер аудитории, если он получен. TXT сохраняется в `Результаты/Сообщества_дата_время.txt`; доступны сохранение TXT/CSV, копирование ников/ссылок, остановка и продолжение поиска. В каждом запуске выводятся все найденные подходящие сообщества, без дублей по ID. Они хранятся в отчётах и контрольных точках отдельно от личных контактов и не изменяют память о ранее найденных людях. При повторном экспорте устаревшие ники сообществ проверяются по ID.

В режиме сообществ можно задать предел от 1 до 10000, в том числе 1000. Это верхняя граница, а не обещание получить столько результатов: выдача Telegram ограничена, бюджет API действует отдельно. В поиске личных контактов предел остаётся 300. Ошибки настроек показываются также в статусе и журнале, а изменённые настройки сохраняются при закрытии окна до запуска поиска.

Публичные ссылки из поля **Свои группы / каналы** проверяются первыми. Чтобы искать по новой выдаче Telegram, очистите этот список; если оставить только ссылки без ключевых слов, будут выведены сведения об указанных сообществах. Кнопка **База контактов TXT** по-прежнему относится к накопленной базе людей.

### Только РФ

Галочка **Только РФ (по публичным признакам)** под полем города действует для нового поиска сообществ и контактов. Ищет явное указание России/РФ, российской юрисдикции или города/региона из встроенного словаря в названии и описании сообщества. Например: «Юристы России», «ГК РФ», «Москва», «Казань». Это приблизительная оценка направленности сообщества, а не проверка страны проживания владельца или участников. Один русский язык, ник или телефон не считаются основанием.

Без признака РФ, при явном исключении России или упоминании другой страны из словаря сообщество пропускается. Словарь неполный; российские сообщества без распознаваемого указания региона также могут быть пропущены. Для уточнения можно дополнительно задать город. В режиме «Только каналы и группы» ключевые слова и город по-прежнему проверяются только в названии; описание используется отдельно для РФ и аудитории.

Для поиска кандидатов сначала выполняются запросы со словом «Россия», затем исходные запросы. Это не готовый фильтр страны в Telegram: каждый кандидат всё равно проверяется по указанным выше признакам. Все запросы учитываются в общем бюджете API.

Признак РФ сохраняется в карточке сообщества, TXT/CSV и отчёте. Перед экспортом устаревшего результата с фильтром РФ описание проверяется снова; неподходящие и непроверенные результаты исключаются. Применяется обычный кеш описаний и общий бюджет API, при ограничении Telegram поиск останавливается. Галочка сохраняется при закрытии; при продолжении незавершённого поиска используется его исходное значение. Старые выгрузки и общая база контактов не фильтруются задним числом.

## Ограничения и продолжение

Начальные значения: **30 сообществ, 100 новых контактов, 300 API-операций, 15 последних публикаций, 24 часа для кеша описаний**. Существующие пользовательские настройки сохраняются. При поиске контактов доступно до 300 сообществ, при поиске самих сообществ — до 10000. Публикации: до 100 на сообщество; операции/новые контакты: до 10000. Это ограничения объёма работы, а не гарантированно безопасные лимиты Telegram.

Один механизм выдерживает паузу минимум 2 секунды между поисковыми RPC и считает категории: поиск, описания, публикации, проверка пользователей, администраторы. Учитываются и дополнительные RPC внутри методов Telethon. До отправки операции её счётчик сохраняется в SQLite. Служебное подключение/вход и транспортные пакеты в счётчик поисковых операций не входят. Повторные попытки RPC Telethon отключены. Версия Telethon закреплена, её внутренний шлюз `_call` покрыт отдельным тестом.

**Любой FloodWait немедленно останавливает поиск**, даже на одну секунду. Время окончания сохраняется в `.local/cooldown.json`; перезапуск, изменение API и выход из аккаунта его не сбрасывают. В интерфейсе отображается оставшееся время. Оба режима ограничения останавливают и сохраняют результаты; второй дополнительно показывает уведомление. Автоматического возобновления нет.

**Продолжить незавершённый поиск** доступно после остановки/ошибки/сбоя и истечения FloodWait. Сохраняются найденные ID, очередь сообществ, завершённые этапы, счётчики и прежняя классификация «Новый». Завершённые этапы не выполняются снова. Незавершённый этап повторяется: после аварийного завершения это позволяет восстановить контакты, которые ещё находились в пакете записи. Запись истории и контрольной точки выполняется одной транзакцией, отчёты записываются на границах этапов, каждые 10 изменённых контактов или через 5 секунд при поступлении контакта. TXT/JSON при необходимости восстанавливаются из контрольной точки.

Лимиты операций и новых контактов относятся ко всему продолжаемому запуску. Если бюджет исчерпан, **увеличьте соответствующее значение перед продолжением**. При продолжении используются исходные слова/роли/фильтры; из текущих настроек принимаются бюджеты сообществ, новых контактов, API-операций и принудительное обновление. Другая тема запускается обычной кнопкой. Предлагается последний незавершённый поиск; более ранние контрольные точки остаются в SQLite.

Блокировки файлов исключают одновременную работу с одной сессией. Дополнительная блокировка по отпечатку ключа авторизации защищает и одинаковую сессию, скопированную в другую папку на этом Mac. Во время поиска недоступны изменение API, очистка и параллельный экспорт.

## История, кеш и повторный экспорт

История общая для всех тем, ключ — **Telegram ID**. Смена ника не делает аккаунт новым; старые имена остаются в таблице aliases. При переходе ника другому ID новый владелец считается новым, а прежний ID не экспортируется под чужим ником. В автоматический TXT и обычный CSV попадают новые контакты. **Вся база TXT** выбирает все накопленные аккаунты с теми же фильтрами экспорта.

Статусы: **Новый**, **Ранее найден**, **Проверка не завершена**. Последний означает, что доступный ник из текста пока не удалось подтвердить либо устаревший контакт не прошёл повторную проверку. Такие строки не попадают в TXT/CSV. Не удалось проверить контакт — он не записывается как новый в историю.

Кеш хранит ID, username, название, описание, размер аудитории, ID закреплённой публикации и время получения метаданных. Свежие описания используются повторно; публикации и доступные администраторы проверяются заново в каждом новом поиске. **Принудительно обновить описания** / **Обновить кеш при следующем поиске** обходят кеш; TTL `0` всегда запрашивает описание. При истечении TTL метаданные обновляются. Изменения описания внутри TTL могут быть видны только после обновления; кеш не подтверждает отсутствие новых сведений. Для максимально свежей проверки используйте принудительное обновление.

Перед повторным экспортом устаревший username проверяется по ID через Telegram; используются access hash из защищённой сессии. Изменившийся ник обновляется, недоступные/неподтверждённые аккаунты пропускаются. При FloodWait или исчерпании бюджета выгрузка не создаётся: увеличьте бюджет или дождитесь ограничения и повторите. **Открыть TXT** открывает уже созданный исторический файл; он отражает дату первоначального поиска и не переписывается. Самостоятельный вызов низкоуровневого `ContactHistory.export_txt()` возвращает последние локально известные имена без сетевой проверки; интерфейс его для повторного экспорта не использует.

Миграция прежней SQLite добавляет поля/таблицы без удаления записей. Прежние JSON с Telegram ID импортируются один раз; списки каналов не считаются аккаунтами. Импорт старого отчёта не считается новой проверкой ника в Telegram. Прежние TXT/CSV не изменяются.

## Подтверждение владельцев

- **Подтверждённый создатель** — Telegram API вернул `ChannelParticipantCreator`.
- **Администратор** — доступный список администраторов Telegram API.
- **Предполагаемый владелец** — публичное указание владельца в описании/публикации, требующее оценки.
- **Другой контакт** — текстовый контакт администратора, рекламы, рекламодателя, деловой или без ясной роли. Подробная роль сохраняется в источниках и CSV.

Рекламный менеджер не считается владельцем. Контакт из рекламной публикации не доказывает, что человек владеет рекламируемой компанией. Для каждого подтверждения сохраняются метод, дата, ID/ссылка сообщества и ссылка на пост, когда она доступна. Старые отчёты могут не содержать даты и ID сообщества.

Город проверяется по названию и описанию сообщества, а не по геолокации человека. Поиск ограничен выдачей Telegram. Списки администраторов могут быть закрыты; имена без публичного username не выгружаются. Доступность ника не гарантирует возможность написать пользователю. Боты включаются отдельной настройкой. Программа не отправляет сообщения, не вступает в группы, не приглашает людей, не раскрывает анонимных администраторов, не переключает аккаунты/прокси для обхода ограничений.

## Хранение и резервные копии

Установленная копия: `~/Library/Application Support/Telegram Contacts/`. Рабочий проект остаётся отдельно. Приватные каталоги и результаты имеют права `700`, файлы `600`; запись выполняется атомарно с синхронизацией на диск.

- `.local/config.json`: API ID, телефон и ссылка на запись Keychain. **API Hash находится в macOS Keychain**, в сервисе `local.tgsearch.contacts`.
- `.local/telegram.session`: **зашифрованная AES-256-GCM копия SQLite Telethon**. База с ключом авторизации и access hash во время работы находится в памяти. Уникальный случайный nonce на запись; ключ шифрования — в Keychain, доступный на этом Mac при разблокированной связке ключей. При миграции содержимое проверяется и атомарно заменяется зашифрованным по прежнему пути. Вход сохраняется.
- `.local/contacts.sqlite3`: история, источники, кеш и контрольные точки. `.local/reports/`: JSON. `Результаты/`: TXT/CSV. Эти публичные контактные данные защищены правами macOS, **не зашифрованы**.
- `.local/diagnostics.jsonl`: только тип ошибки, действие и расположение кода. Сообщения исключений, номера телефонов, API Hash, коды/пароли/QR и сессии туда не записываются. Содержимое известных секретов/32-значных hex-строк очищается из текстовых источников/CSV.

При недоступном Keychain миграция не уничтожает исходные настройки/сессию и не переходит на незашифрованное хранение. Для выхода используйте **Выйти из аккаунта на этом компьютере** или управление устройствами официального Telegram. При действующем ограничении сетевой выход следует повторить после его окончания.

`.local`, результаты, сессии, базы, архивы и окружения исключены из Git. Установщик добавляет `.local` в исключения Time Machine; другие средства резервного копирования настройте отдельно. **Не создавайте незашифрованные архивы приватных каталогов.** Во вкладке **Данные и хранение** можно зашифровать существующий архив (до 128 МБ) в новый `.enc`. Исходник сохраняется: его удаление — отдельное действие пользователя. Старые архивы, созданные до обновления, автоматически не удаляются.

Шифрованная копия требует **исходного Keychain этого Mac**. Ключ не включается в Git/архив, перенос одного `.enc` на другой Mac недостаточен. Для нового компьютера можно установить программу и войти заново. Восстановление `.tar.gz.enc` в новую папку на исходном Mac, без создания промежуточного открытого архива:

```python
from tgsearch.maintenance import restore_backup
restore_backup('/полный/путь/копия.tar.gz.enc', '/полный/путь/новая_папка')
```

**Данные и хранение** позволяет задать срок хранения промежуточных отчётов (по умолчанию 30 дней) и подтвердить удаление устаревших завершённых JSON. Последний отчёт, незавершённые и старые отчёты прежних версий сохраняются. Очистка не удаляет историю и отдельные выгрузки. Кнопка **Удалить локальную историю и отчёты…** после подтверждения удаляет SQLite и стандартную папку JSON; вход, настройки, FloodWait и отдельные TXT/CSV/архивы остаются. После этого прежние аккаунты снова считаются новыми. На SSD/APFS удаление файла не гарантирует физическое стирание его копий в снимках диска.

## Установка и проверка

Нужен Python с Tkinter (на этом Mac Python 3.15 / Tk 9). Зависимости закреплены в `requirements.txt`; Keychain используется через системный Security.framework без передачи секретов командной строке.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -W error::ResourceWarning -m unittest discover -s tests -v
.venv/bin/python install_local.py
```

Перед обновлением закройте программу. Установщик блокирует активные копии, обновляет код/зависимости, выполняет миграции установленным Python, сохраняет существующие настройки, сессию, историю и результаты и обновляет значок рабочего стола. Прямой запуск: `.venv/bin/python app.py`.

Тесты: извлечение/роли/ссылки, ранжирование, фильтры, ID/aliases, повторные экспорты, реальные точки перехвата RPC с подставленным транспортом, лимиты и persistent FloodWait, TTL/refresh, остановка/ошибка/аварийное завершение отдельного процесса, возобновление, транзакции/миграции, шифрование и отказ Keychain, приватность и установщик macOS. Сеть Telegram и ключи пользователя в автоматических тестах не используются. Живой FloodWait намеренно не вызывается; ограничения доступа, новые способы входа и системные диалоги Keychain проверяются вручную по мере возникновения.
