# Telegram Контакты

Локальная программа для macOS с окном на русском языке. Основана на [osipart777888-coder/tg-search](https://github.com/osipart777888-coder/tg-search), использует Telethon и Telegram API.

## Как пользоваться

1. Откройте **Telegram Контакты.app** на рабочем столе. Альтернативный запуск: `Запустить.command` в папке проекта.
2. На вкладке **Вход в Telegram** введите свой номер с кодом страны и нажмите **Получить код**. API-настройки на этом компьютере уже заполнены.
3. Введите код, который пришлёт Telegram, и при необходимости облачный пароль двухэтапной проверки. Вводите их прямо в программу.
4. Откройте **Поиск контактов**, выберите тему: строители, юристы, недвижимость, красота, медицина, авто, образование, бизнес, IT или свою тему. Слова можно менять и разделять запятыми.
5. Выберите, кого искать, тип сообществ, город и размер аудитории, если они важны. Нажмите **Начать поиск**.
6. Нажмите **Открыть TXT**. Программа автоматически создаёт отдельный файл `Новые_ники_дата_время.txt` в папке **Результаты**. На рабочем столе есть ссылка **Результаты Telegram** на эту папку; в программе — кнопка **Папка**. В файле только новые контакты, по одному нику на строку. Формат UTF-8 с BOM подходит для Блокнота и TextEdit.

Кнопка **Сохранить TXT как…** позволяет выбрать свою папку для новых контактов текущего поиска. **Источники CSV** — дополнительная выгрузка новых контактов с ролями, каналами и ссылками на публикации. Выбор строки в таблице показывает подтверждение; двойной щелчок открывает профиль.

## История и повторные поиски

Программа хранит постоянную базу аккаунтов по **Telegram ID**, общую для всех тем и запусков. При повторном поиске уже известные аккаунты не попадают в новый TXT, даже если сменили ник. Изменившийся ник обновляется в общей базе; прежние варианты остаются в истории. Если ник перешёл другому аккаунту с другим ID, этот аккаунт считается новым, а устаревший ник старого владельца больше не выгружается из общей базы.

Счётчики показывают найденные и новые аккаунты отдельно. В таблице **В TXT** означает новый контакт этого запуска, **В базе** — уже найденный раньше. Если новых контактов нет, новый TXT будет пустым. Сообщества проверяются повторно, поскольку в них могут появиться новые контакты.

Кнопка **Вся база TXT** выгружает все накопленные контакты по последним известным никам. Файлы прежних поисков сохраняются. При первом запуске обновлённой версии контакты автоматически переносятся из прежних JSON-отчётов с Telegram ID; TXT-файлы со списками каналов не принимаются за аккаунты людей.

История находится в `.local/contacts.sqlite3` внутри установленной копии и сохраняется при закрытии, выходе из Telegram и переустановке обновления. При удалении этой базы и старых JSON-отчётов программа потеряет память о ранее найденных аккаунтах. Старые выгрузки отражают ники на момент их создания; обновлённые ники доступны в **Вся база TXT**.

Если код не приходит, нажмите **Войти по QR** на вкладке входа. На телефоне: **Telegram → Настройки → Устройства → Подключить устройство**, затем отсканируйте QR и подтвердите вход. При включённой двухэтапной проверке программа попросит облачный пароль. QR обновляется при истечении срока, сохранять его в файл не нужно. Этот способ не запрашивает SMS.

При входе по номеру программа показывает способ доставки, указанный Telegram: служебный чат, SMS или почта. Повторная отправка ограничена таймером Telegram. Журнал `.local/diagnostics.jsonl` содержит типы ошибок и доставок; номера, коды, пароли и QR-токены в него не записываются.

## Кого программа ищет

- Владельцев из доступного списка администраторов и контакты, явно указанные как владельцы в тексте.
- Администраторов из доступного списка и контакты с соответствующей подписью.
- Контакты для покупки рекламы, подписанные «по рекламе», «сотрудничество» и т. п.
- Контакты, явно названные рекламодателями, и контакты из публикаций с признаками рекламы (`#реклама`, `erid`, «спонсор»). **Контакт из объявления не означает доказанного владельца рекламирующейся компании.**
- В режиме **Все опубликованные контакты** — также контакты без подписи роли. Боты включаются отдельным флажком.

Проверяются описания, текущий закреплённый пост и выбранное количество последних публикаций. Каждое имя проверяется через Telegram: удалённые/несуществующие аккаунты и ссылки на каналы исключаются. Наличие ника не гарантирует возможность написать: у пользователя могут быть ограничения на сообщения.

## Фильтры и охват

- Город ищется в названии или описании сообщества; это **не геолокация пользователя**. Если нужный город там не указан, сообщество пропускается.
- Минимум участников применяется только к сообществам с известным размером аудитории.
- До 300 сообществ и до 100 последних публикаций на сообщество за один запуск. Закреплённая публикация проверяется дополнительно. По умолчанию: 50 сообществ, 30 публикаций.
- Поле **Свои группы / каналы** принимает публичные `@ники` и `https://t.me/ник` через запятую. Они проверяются первыми с теми же фильтрами. Если нужны только они, очистите поисковые слова.
- Поиск Telegram ограничен его выдачей. Программа **не может перечислить все тематические каналы Telegram**, узнать скрытого владельца или установить личность анонимного администратора. Недоступные списки администраторов пропускаются.
- Пауза между обращениями — 2 секунды. Короткие ограничения Telegram ожидаются; при ограничении свыше минуты поиск останавливается с сохранением найденного. **Стоп** также сохраняет частичный результат.

Программа не вступает в сообщества и не отправляет сообщения. Данные обрабатываются локально; сетевые обращения идут в Telegram API. Первый поиск требует входа пользователя. Автоматические тесты используют вымышленные данные и не подменяют результаты реального поиска.

## Локальные данные

Установленная копия программы на macOS находится в `~/Library/Application Support/Telegram Contacts/`. Это позволяет запускать её со значка без запроса доступа ко всей папке «Документы». Исходный проект остаётся отдельно в рабочей папке.

API-настройки и телефон находятся в `.local/config.json` внутри установленной копии; сессия входа — в `.local/telegram.session`. Они исключены из Git, папка имеет права `700`, файлы — `600`. Пароль 2FA и одноразовые коды не сохраняются. Источники результатов сохраняются в `.local/reports/`, основной TXT — в `Результаты/`.

Не передавайте `.local` другим людям: сессия даёт доступ к аккаунту. Для завершения сессии используйте **Выйти из аккаунта на этом компьютере** либо раздел активных устройств в Telegram.

## Установка на другом Mac

Нужен Python с Tkinter (проверено на установленном Python 3.15 / Tk 9). Из папки проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python install_local.py
```

Введите свои API-настройки и войдите в Telegram. Установщик копирует программу и создаёт отдельное окружение в Application Support, затем добавляет значок и ссылку на результаты на рабочий стол. Для применения изменений в исходниках закройте программу и повторите `install_local.py`; существующие настройки и сессия сохраняются.

Прямой запуск:

```sh
.venv/bin/python app.py
```

Проверка логики поиска, извлечения, фильтров, экспорта, остановки и ограничений:

```sh
.venv/bin/python -m unittest discover -s tests -v
```
