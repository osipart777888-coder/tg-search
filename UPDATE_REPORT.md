# Отчёт об обновлении Telegram Контакты

Дата проверки: 20 октября 2026. Окружение: macOS, Python 3.15, Tk 9, Telethon 1.45.0.

## Добавленные функции

- Единый шлюз поисковых RPC с интервалом, бюджетами и счётчиками по пяти категориям. Учитываются дополнительные обращения из методов Telethon. При любом FloodWait — немедленная остановка, сохранение срока и блокировка продолжения до его окончания.
- Блокировка одновременного использования сессии, включая копии одного ключа авторизации в разных папках Mac.
- Кеш метаданных сообществ, TTL и принудительное обновление. Свежие публикации и доступные администраторы проверяются в каждом новом поиске.
- Пакетные транзакции SQLite, контрольные точки этапов и очереди, ручное продолжение после остановки/сбоя. Восстановление TXT/JSON из SQLite при прерывании записи отчёта.
- Статусы новых/известных/непроверенных контактов, дедупликация по ID, история username, защита от переиспользования ника другим ID.
- Категории создателя API, администратора API, предполагаемого владельца из текста и других контактов. Фильтры экспорта по типу и достоверности; CSV содержит метод, дату, ID, сообщество и подтверждающий источник.
- Проверка устаревших ников по ID перед повторным экспортом. Непроверенные контакты не экспортируются.
- API Hash в macOS Keychain; SQLite-сессия Telethon работает в памяти и сохраняется с AES-256-GCM. Перенос существующей сессии сохраняет ключ авторизации, entity access hash и состояние. Права каталогов 700, файлов 600; исключения Time Machine; секреты исключены из Git/диагностики.
- Настройки хранения, очистка истории/отчётов с подтверждением, шифрование резервного архива и восстановление в новую папку. Выход из Telegram и замена API сохранены.
- Обновление установщика и ярлыков: явная архитектура Python для совместимости с модулем шифрования; вкладка входа прокручивается при небольшой высоте окна.

## Проведённые проверки

Команда: `.venv/bin/python -W error::ResourceWarning -m unittest discover -s tests -v` — **80 тестов успешно**. `pip check` — зависимости согласованы. Python-компиляция и проверка синтаксиса zsh прошли.

Автоматически проверены роли/извлечение/ранжирование, реальная точка перехвата RPC с подставленным транспортом, бюджеты, сохранённый FloodWait, кеш/TTL/refresh, Stop, ошибки и аварийное завершение отдельного процесса, продолжение, атомарность транзакций, восстановление после записи SQLite до JSON, ID/aliases/переход ника другому ID, миграции, проверка экспорта, отказ Keychain, повреждение шифрованного файла, отсутствие секретов в диагностике и экспортах, сохранность данных установщиком.

На этом Mac отдельно проверены системный Keychain и шифрованная сессия после повторного открытия. `install_local.py` выполнен. Ярлык рабочего стола открывает приложение, действующий аккаунт восстанавливается. Предыдущие **23 ID** истории сохранены; **8 прежних файлов отчётов/выгрузок совпадают побайтно**, SQLite integrity_check — `ok`.

Выполнен ограниченный живой поиск по одному прежнему юридическому сообществу: 5 поисковых API-операций, один подтверждённый существующий контакт из публичного текста; этап получения администраторов вернул ошибку API. Публикация результатов этой проверки изолирована от основной истории и прежней выгрузки. FloodWait не получен. Подтверждение создателя через API проверено автоматически на моделируемых ответах; получение создателя реального канала не подтверждалось.

Создана зашифрованная копия перед миграцией; проверено восстановление в новую временную папку. Ранее созданный полный архив переведён в шифрованный формат с проверкой SHA-256 исходного содержимого после расшифровки. Исходное содержимое архивов сохранено.

## Ограничения и ручная проверка

- Живой FloodWait намеренно не провоцировался; его обработка проверена подставленными ответами, включая запрет повторного обращения из нового движка.
- Системные диалоги при заблокированном/запрещённом Keychain, отзыв Telegram-сессии и новый вход по SMS/QR после обновления не проверялись на действующем аккаунте. Отказ хранилища и сценарии входа покрыты автоматическими тестами.
- Массовый поиск по тысячам аккаунтов и получение открытого создателя в реальном сообществе требуют отдельной обычной проверки пользователем. Гарантий отсутствия ограничений Telegram нет.
- Описание может измениться внутри TTL. Для немедленного обновления включите принудительную проверку. Кеш не доказывает отсутствие новых сведений.
- История и пользовательские TXT/CSV защищены правами macOS, но не зашифрованы. Другие системы резервного копирования и прежние снимки Time Machine требуют отдельного управления пользователем.
- Для шифрованной сессии и архивов нужен исходный Keychain этого Mac. Его утрата препятствует восстановлению; на другом Mac можно войти заново.
- Удаление с SSD/APFS не гарантирует физического стирания снимков и сторонних копий. Проверка очистки выполнена на временных данных; текущая пользовательская база не удалялась.
